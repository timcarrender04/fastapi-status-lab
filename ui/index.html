Dockerfile

FastAPI and this page run only in the container. docker compose up --build builds this file. Do not start uvicorn on the laptop.

  1. FROM python:3.12-slim The base image. Python lives in the image.
  2. WORKDIR /app Later paths are /app inside the image, not a folder on the laptop.
  3. COPY requirements.txt . then RUN pip install. Install before the code. An edit to app.py does not reinstall FastAPI.
  4. COPY app.py . and COPY ui ./ui. The API and this page both go into the image.
  5. EXPOSE 8000 Documents the port inside the container. It does not publish that port.
  6. CMD ["uvicorn", "app:app", "--host", "0.0.0.0", "--port", "8000"] 0.0.0.0 is required. 127.0.0.1 would answer only inside the container, and the published port could not reach it.

docker-compose.yml publishes 8000:8000. That is the host port, then the container port. Curl and this page use the host port.
